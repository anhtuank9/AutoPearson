# Security and privacy

## Sensitive files

`.env`, `diagnostics/` and `.pearson-profile/` are intentionally ignored by Git. Diagnostic files can contain course content and personal information. Review and redact them before sharing.

Never paste Pearson credentials into a GitHub issue, pull request, commit or command-line argument.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for security issues. Include only the minimum reproduction details and remove account or course information.
